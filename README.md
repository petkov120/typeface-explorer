# Typeface Explorer

Chrome extension. Click text on a live page, try a typeface or a heading/body pairing, copy CSS.

The point is a fast way to slot in different fonts and pairings on a real layout instead of changing code and prompting.

No accounts. No backend. Overlay only — host page CSS is never rewritten.

See [SPEC.md](SPEC.md) for the v0.1 build spec.
